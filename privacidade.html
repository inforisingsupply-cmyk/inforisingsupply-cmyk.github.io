Política de Privacidade — gil-postador

Última atualização: 20/11/2026

O gil-postador é uma ferramenta pessoal, usada apenas pelo dono da conta Rising Supply Streetwear, para publicar os próprios vídeos no TikTok, YouTube e Instagram.

Dados acessados: informações básicas do perfil (nome de usuário e ID) e permissão para enviar vídeos à própria conta.

Uso: os dados servem só para publicar os vídeos do próprio dono. Não são vendidos, compartilhados nem usados para publicidade.

Armazenamento: os tokens de acesso ficam somente no computador do dono, nas variáveis do Windows. Nenhum servidor externo guarda esses dados.

Serviços de API do YouTube: o gil-postador usa os Serviços de API do YouTube (YouTube Data API v3: videos.insert para enviar o vídeo e channels.list para confirmar o canal conectado). Ao usar o gil-postador, o usuário também fica sujeito à Política de Privacidade do Google. Os dados obtidos da API do YouTube (ID e nome do canal) não são armazenados nem compartilhados; ficam só na memória durante o envio.

Revogação e exclusão: o acesso pode ser revogado a qualquer momento em security.google.com/settings/security/permissions (Google/YouTube) e em Configurações > Segurança > Apps (TikTok). Ao revogar, os tokens deixam de funcionar. Para pedir a exclusão de qualquer dado, escreva para o contato abaixo; tudo é apagado em até 7 dias.
